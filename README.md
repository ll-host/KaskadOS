KaskadOS
========

Управление сборками
-------------------

Запустите `./kaskados-manager.sh` из корня проекта. В графической сессии
откроется Qt-интерфейс со сборкой ISO и пакетов, публикацией, состоянием
артефактов и живым журналом выполнения. Первый запуск автоматически собирает
небольшое приложение в `build/kaskados-manager`.

Текстовый интерфейс сохранён как аварийный режим:

```bash
./kaskados-manager.sh --tui
```
